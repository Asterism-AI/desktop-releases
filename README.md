# Asterism AI Desktop releases

Signed and notarized macOS builds of Asterism AI Desktop are published here
as GitHub Releases. This repository holds releases only; the app's source is
private.

Download the latest stable build from
[Releases](https://github.com/Asterism-AI/desktop-releases/releases/latest),
or from <https://asterism.derekdylu.com/download>.

The desktop app checks this repository for updates.
